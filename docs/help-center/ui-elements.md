# Generic UI Elements

## New button
Primary create action for current screen entity.

## Create menu
Adjacent quick-create actions for related entities.

## Filters
Use filter chips/dropdowns to narrow results.

## Row interactions
- Single click: details context
- Double click: edit context (where supported)

## Toasts
Should be human-readable and action-oriented (e.g., Undo/Close), not raw payload dumps.
