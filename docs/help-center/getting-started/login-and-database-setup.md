# Login and Database Setup

## What this covers
- Signing in
- Understanding Database/Profile switcher
- Creating/selecting a database profile (Primary / Showcase)

## Steps
1. Open Cabinet and sign in.
2. In the top-left sidebar switcher, choose **Database**.
3. Select an existing profile (e.g., Primary DB) or create a new one.
4. For demos, select **Showcase DB** when available.
5. Confirm data context changed by checking Inventory/Wishlist content.

## Tips
- Database/profile selection changes app-wide data context.
- Collections are not databases; they are grouping buckets within a database profile.
