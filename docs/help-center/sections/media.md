# Media

## Use Media for
- Reviewing uploaded photo and evidence assets across Cabinet
- Finding assets that are not linked to Inventory or Wishlist records
- Checking analysis status before assignment follow-up

## Current workspace slice
- **All** shows media assets as cards by default.
- **Unlinked** filters to assets that still need assignment review.
- Asset cards show preview, upload time, analysis status, confidence when available, and linkage state.
- Open, analyze, assign, archive, upload, and download actions are visible as first-class controls while backend ingestion and assignment slices continue.
