# Wishlist

## Use Wishlist for

- Tracking items to acquire
- Prioritizing purchase decisions
- Converting acquired items into owned inventory state

## Common actions

- **New**: create wishlist entry
- **Create menu**: quick-create related entities
- **Cost/Qty**: use minus/plus controls for one-step edits, or type exact numeric values directly
- Filter by status/priority and sort by key fields

## Planning with taxonomy

- Wishlist entries use the same configured item type, condition scale, and packaging grade taxonomy as Inventory.
- Set item type, condition, and packaging grade while planning a purchase so wishlist-to-inventory conversion preserves the collector classification on the owned item.
- If a wishlist entry points at an inventory record, the taxonomy fields should stay aligned with the active profile's Settings > Categories configuration.
