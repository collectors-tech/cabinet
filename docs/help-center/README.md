# Cabinet Help Center Docs Plan

This folder contains user-facing Help Center content drafts.

## Structure
- `getting-started/`
  - login, database/profile switching, first-run setup
- `sections/`
  - one guide per app section
- `ui-elements.md`
  - shared UI patterns used across sections

## Authoring Rule
- Keep one doc per section/feature area.
- Keep actionable steps and screenshots-friendly headings.
- Link each guide from Help Center index in-app.
