# Docs Policy

OpenSpec is the normative source of requirements.

## Where Requirements Live
- Product/domain requirements: `openspec/specs/*/spec.md`
- UI foundation and screen requirements: `openspec/specs/ui-*/spec.md`
- Requirement/use-case mapping: `openspec/specs/README.md`

## What `docs/` Contains
- Legacy/historical planning content (non-normative)
- Operational references (API docs, auth setup, migration workflow)
- Migration tracking and coverage artifacts

## Migration Tracking
- Catalog: `docs/OPENSPEC_MIGRATION_CATALOG.md`
- File-by-file legacy status: `docs/LEGACY_DOCS_STATUS.md`
- Test mapping: `docs/OPENSPEC_TEST_MATRIX.md`
- Workflow: `docs/OPENSPEC_WORKFLOW.md`
