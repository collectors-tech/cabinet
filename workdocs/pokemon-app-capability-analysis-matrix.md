## Analysis dimensions (per app)
1. Onboarding and auth (email/social/passkey)
2. Collection model (owned/wishlist/variants/condition/language)
3. Price tracking (source, frequency, historical charts, alerts)
4. Set/card discovery and search quality
5. Portfolio valuation and analytics
6. Inventory organization (folders/tags/status/priorities)
7. Media/photos and OCR/scan support
   - Capture flow type (live camera vs upload)
   - Single-card vs batch scan support
   - Recognition method clues (OCR text, image matching, barcode, set-symbol detection)
   - Confidence UX (top match, alternates, manual override)
   - Scan latency + failure/retry behavior
   - Privacy/offline processing indicators
8. AI/chat assistance capability
9. Marketplace/export/import integrations
10. Mobile experience and capture workflow
11. Collaboration/multi-user roles
12. Performance + UX polish (table/list/card views)
13. Data portability and backup
14. Privacy/security posture
15. Monetization/plan gating and feature entitlements

## Required outputs
- Per-app capability scorecard
- Gap-to-Cabinet mapping (must-have / should-have / nice-to-have)
- Priority recommendation wave (P1/P2/P3)
- OpenSpec requirement IDs to add/update per gap
- GitHub issues created one-per-gap item

## Scoring model
- 0 = absent
- 1 = minimal
- 2 = usable
- 3 = strong
- 4 = best-in-class
