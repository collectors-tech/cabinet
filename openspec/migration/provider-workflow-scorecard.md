## Audit findings to enforce now
1. Every provider issue must include full acceptance criteria and test evidence paths.
2. Mock lane and live lane evidence links are mandatory for closure.
3. Provider docs deliverables must be listed explicitly in each issue body.
4. No close without all 10 stages checked in issue checklist.

## Blocking policy
- If any stage fails, keep issue open and post blocker with first actionable fix path.
- Move to next provider only when current blocker is recorded.
