# Cabinet Browser Companion 0.1.0 beta 1

This private-beta candidate provides one modular Manifest V3 host for Chrome and
Edge, secure local Cabinet pairing, profile-scoped integration discovery,
durable item/image observations, and user-present Frontline Hobbies and Bonza
Slot Cars capture modules.

Distribution is a verified ZIP that the beta reviewer extracts and loads as an
unpacked extension. It is not a browser-store listing, CRX installer, enterprise
policy package or automatic-update channel. Chrome and Edge packages are kept
separate so their exact browser/version acceptance evidence remains unambiguous.

Known release gates remain the real user-present provider journeys and the exact
packaged Windows acceptance in #1869. Firefox, Safari and Brave are not claimed
as validated targets in this release.
